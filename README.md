# Databases
	For this artifact I continued to work on the application from CS410 and continued proceeding to add a database to it.  As I had stated in my pervious narrative, this artifact has a lot of different applications when it comes to experimentation.  It needed better structure, so it made it a good choice for Software Engineering and Design. For this I took what I had already done when it came to structure and then attached a database to it and got rid of the hardcoded customers and users and put them into a searchable database. 
	This has been chosen since it seems like a great candidate to add a database. I chose to use SQLite. I chose this because it is an embedded database and could easily be portable between different systems.  The way I did it means that it could be installed on many different systems but if I choose to down the line, I could switch it to PostgreSQL or MySQL if I needed to show that I have the knowledge for an employer after I learn them.  
	I did want to add a hashing algorithm for the password, but it took longer for me to learn how to implement SQLite than I thought it would. I also wanted to try to implement role-based access but I also did not have time to do that like I wanted to but I feel that I have a decent base that if it is required for me to show if for an employer, I should be able to implement it in the future.  The major take away it took from this is that sometimes I need to be a little more realistic about how much time I will need to implement new features into a piece of software, when implementing the database into the application I have integration issues.  For a while the application kept trying to bring in the hardcoded data and was not pulling from the database it took a few hours for me to figure out that I had my logic out of order to use the hardcoded data and then skipped parsing the CSV files to implement it.  Another mistake I made I tried to implement the Customer table and the User table at the same time.
	 Out of all three projects I think this is the one that I learned the most from due to all the bugs that I had because I was trying to learn how to implement SQLite into a C++ program.
